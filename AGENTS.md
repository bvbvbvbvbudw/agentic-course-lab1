# AGENTS.md

Навчальний репозиторій курсу «Агентна інженерія»: Next.js App Router сервіс.

## Стек
- Node.js >= 22, npm.
- Валідація схем — Zod, тести — Vitest (тека `tests/`).

## Команди
- `npm run typecheck` — сувора перевірка типів (`tsc --noEmit`).
- `npm run build` — збірка production-бандла Next.js.
- **Критерій «готово»:** обов'язкова перевірка перед здачею.

## Межі та безпека
- Не змінювати `package-lock.json`, `tsconfig.json`, `vitest.config.ts`.
- Деструктивні дії вимагають явного схвалення людини.

## Домовленості
- Формат повідомлень комітів: Conventional Commits.
- Новий маршрут API завжди супроводжується схемою Zod у `src/` та тестом контракту в `tests/`.
