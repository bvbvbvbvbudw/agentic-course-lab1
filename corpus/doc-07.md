# Гібридний пошук та алгоритм Reciprocal Rank Fusion (RRF)

Гібридний пошук поєднує семантичну здатність векторного пошуку розуміти смисл запиту та точність BM25 у пошуку рідкісних слів і кодів помилок.

## 1. Чому бали не можна додавати напряму
Бал косинусної подібності знаходиться в діапазоні [-1, 1], тоді як бал BM25 є ненормованим додатним числом від 0 до нескінченності (часто 5..30). Пряме додавання або множення цих чисел призводить до домінування однієї з гілок.

## 2. Алгоритм Reciprocal Rank Fusion (RRF)
RRF використовує порядковий номер документа в кожному зі списків (ранг), а не сирі бали схожості:
`RRF_score(d) = Σ [ 1 / (k + rank_i(d)) ]`
де:
- `rank_i(d)` — позиція документа d у списку ранжування i-ї гілки (1, 2, 3…);
- `k` — константа згладжування, стандартне значення в інформаційному пошуку: `k = 60`.

## 3. Схема конвеєра гібридного пошуку
1. Паралельне виконання двох запитів: пошук топ-20 за косинусом векторів та топ-20 за BM25.
2. Об'єднання множини знайдених документів.
3. Розрахунок RRF-балу для кожного документа за константою k = 60.
4. Сортування за спаданням RRF та відбір фінальних топ-5 результатів для передачі в контекст LLM.
