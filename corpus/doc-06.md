# Лексичний пошук BM25 та його параметри

BM25 (Best Matching 25) — це ймовірнісний алгоритм ранжування документів, який спирається на точні збіги термів із урахуванням їхньої частоти та довжини документа.

## 1. Формула ранжування та ключові константи
Бал BM25 для запиту Q до документа D розраховується через суму значень IDF для спільних термів:
- `k1`: коефіцієнт насичення частоти терма (типово 1.2). Він обмежує внесок багаторазового повторення одного й того самого слова в документі.
- `b`: коефіцієнт нормалізації довжини документа (типово 0.75). Значення 1.0 повністю штрафує довгі документи, 0.0 вимикає штраф.
У канонічній реалізації для української мови обираються саме параметри `k1 = 1.2` та `b = 0.75`.

## 2. Особливості токенізації
Для ефективного лексичного пошуку обов'язковим є:
- Переведення у нижній регістр;
- Видалення розділових знаків;
- Спліт за пробільними символами та дефісами;
- Збереження буквено-цифрових кодів (ідентифікаторів помилок, назв функцій).

## 3. Слабкі місця BM25
Лексичний пошук безсилий проти синонімії та описових питань. Якщо користувач запитує «як усунути дефект», а в тексті вжито лише слово «лагодити несправність», BM25 поверне нульовий бал.
