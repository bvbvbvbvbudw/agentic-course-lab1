# Архітектура автономних агентів та агентний цикл

Автономний агент — це обчислювальна система, яка використовує велику мовну модель (LLM) як центральний контролер для розв'язання поставленої задачі через послідовні ітерації спостереження, мислення та дій.

## 1. Цикл ReAct та взаємодія із середовищем
Класичний агентний цикл реалізує патерн ReAct (Reasoning + Acting). На кожній ітерації агент виконує такі фази:
1. Отримання вхідного стану середовища та історії взаємодії.
2. Формування ланцюга роздумів (Thought) щодо наступного кроку.
3. Генерація виклику інструмента (Action / Tool Call) із конкретними аргументами.
4. Виконання інструмента в ізольованому середовищі та отримання результату (Observation).
5. Перевірка критерію зупинки (досягнення мети або помилка).

## 2. Відмінність між агентами та детермінованими конвеєрами
На відміну від детермінованих конвеєрів (Workflows), де послідовність кроків заздалегідь зафіксована у формі спрямованого ациклічного графа (DAG), агент самостійно обирає наступний крок залежно від результату попереднього. Це надає гнучкості при роботі з неструктурованими входами, проте створює стохастичність поведінки.

## 3. Критерій завершення циклу
Агентний цикл завершується, коли модель повертає текстову відповідь без запиту на виклик нових інструментів (stop reason 'stop' замість 'tool-calls'), або коли спрацьовує зовнішнє обмеження бюджету ходів (max_turns).
