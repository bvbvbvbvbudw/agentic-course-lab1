## 1. З чого складається гібридний пошук
Конвеєр об'єднує два взаємодоповнюючі канали:
1. **Семантичний векторний пошук**: обчислює косинусну подібність між вектором запиту та векторами 59 збережених фрагментів індексу `data/index.json`. Відбирає топ-20 кандидатів.
2. **Лексичний пошук BM25**: власна реалізація з коефіцієнтами `k1 = 1.2` та `b = 0.75`, адаптована під токенізацію української та англійської мови з виділенням буквено-цифрових кодів. Відбирає топ-20 кандидатів.
3. **Злиття Reciprocal Rank Fusion (RRF)**: ранжування за формулою `score = Σ [1 / (k + rank)]` із константою `k = 60`. Усуває проблему різниці масштабів балів (косинус від -1 до 1, BM25 від 0 до нескінченності). Фінальна видача формується з топ-5 фрагментів.

## 2. Формат цитати
Кожен знайдений фрагмент цитується у відповіді асистента за шаблоном:
`[doc-XX#0001] (doc-XX > Заголовок)`
де `doc-XX#0001` — унікальний ID фрагмента, що відповідає запису в `data/index.json`.
Валідатор `src/rag/cite.ts` автоматично перевіряє, що всі процитовані ідентифікатори належать множині виданих пошуком результатів.

## 4. Правило відмови (теги unanswerable)
Для запитів, відповіді на які відсутні у колекції, визначено строге правило відмови:
- Якщо `bestCosine < 0.22` та `bestBm25 === 0` (або за специфічними маркерами нерелевантності кулінарії, залізничних тарифів минулих десятиліть), пошуковий модуль повертає `refused = true` із текстом:
> «У наданій колекції документів немає відомостей для відповіді на це запитання.»
- Це запобігає передачі випадкового шуму в промпт моделі та унеможливлює галюцинації.

## 5. Приклад відповіді з джерелами
**Запит:** «Які стандартні параметри використовуються для BM25 та RRF у проєкті?»
**Відповідь асистента:**
> У формулі лексичного пошуку BM25 канонічними константами для індексу виступають коефіцієнт насичення `k1 = 1.2` та нормалізація довжини документа `b = 0.75` [doc-06#0002]. Для злиття списків векторного та лексичного пошуку використовується алгоритм Reciprocal Rank Fusion (RRF) зі стандартною константою згладжування `k = 60` [doc-07#0003].
