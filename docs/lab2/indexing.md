## 1. Колекція
Колекція містить 16 документів у форматі Markdown (`doc-01.md` ... `doc-16.md`), загальним обсягом 33 035 байт (266 рядків). Усі документи ліцензовані під відкритими ліцензіями (CC BY 4.0 / MIT) і не містять конфіденційних даних.

## 2. Правило фрагментації і чому саме таке
- `maxChars`: 800 символів (цільовий максимум фрагмента, адаптований під типовий розмір смислового блоку 150–200 слів);
- `minChars`: 80 символів (запобігає утворенню малозмістовних уривків з одного рядка);
- `overlapChars`: 100 символів (перекриття зберігає граничний контекст між сусідніми фрагментами).

**Обґрунтування:** Структура конспектів побудована на заголовках першого та другого рівнів (`#`, `##`). Алгоритм фрагментації прив'язаний до меж заголовків: при появі нового розділу попередній блок фіксується як завершений, що унеможливлює змішування різних тематичних інваріантів в одному чанку.

## 5. Відтворюваність
Індекс генерується повторно однією командою:
```bash
npx tsx scripts/build-index.ts
```
Для запуску з хмарним провайдером:
```bash
npx tsx scripts/build-index.ts --provider google
```

## 6. Що зберігається для цитування (вхід кроку 05)
Для кожного фрагмента в `data/index.json` збережено:
- `id`: унікальний ідентифікатор формату `doc-XX#0001`;
- `docId`: назва вихідного файлу;
- `heading`: найближчий заголовок розділу;
- `start` та `end`: точні символьні зсуви у вихідному файлі;
- `text`: повний текст фрагмента;
- `embedding`: вектор 768 дійсних чисел.
