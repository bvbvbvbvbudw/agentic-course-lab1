# Журнал автономності · Лабораторна 3

Цей журнал фіксує всі сесії автономної розробки харнеса агентів з оцінюванням якості та перевіркою безпеки.

## Сесія 1 · 2026-11-09 (Заняття 09 · Фабрика задач, брами, верифікатор, зупинення)
- **Інструмент і модель:** Antigravity IDE (Gemini 2.5 Pro)
- **Режим дозволів:** dontAsk (автономний запуск)
- **Що виконувалося:**
  1. Розробка фабрики задач: складено чергу `docs/lab3/tasks.jsonl` (24 задачі з фіксованими бюджетами ходів, таймаутами та детермінованими командами `acceptance`).
  2. Реалізація виконавця `scripts/harness/run-task.ts` та раннера черги `scripts/harness/run-queue.ts` з ізоляцією та збереженням 4 артефактів (`run.json`, `output.txt`, `agent.log`, `patch.diff`).
  3. Побудова ланцюга детермінованих брам у `.github/workflows/gates.yml` (`types` -> `lint` -> `tests` -> `build` -> `record`).
  4. Інтеграція верифікатора на іншій моделі з суворою політикою блокування харнеса (`isHarnessBlocked = report.results.some(r => r.verdict !== 'pass')`).
  5. Розробка 3-рівневого контролера зупинки `src/harness/stop.ts` та запобіжника `src/harness/breaker.ts` (Circuit Breaker з переходом у стан OPEN при 3 збоях).
  6. Складання документації `factory.md`, `gates.md`, `verifier.md`, `stop.md`.
- **Втручання людини:** Жодного. Усі перевірки пройшли автономно.
- **Докази:** Зелений прогін `tests/harness/run-task.test.ts` та сформовані папки прогонів у `docs/lab3/runs/`.
