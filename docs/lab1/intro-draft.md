# Вступ (чернетка) · курсова робота

## Актуальність
Розвиток великих мовних моделей (LLM) останніх поколінь зумовив перехід від парадигми простих чат-асистентів до повноцінних агентних систем (Agentic AI), здатних до автономного планування, багатокрокового використання зовнішніх інструментів та рефлексивного виправлення власних помилок. Проте широке впровадження кодуючих агентів стикається з критичними викликами: висока ймовірність неконтрольованих деструктивних змін файлової системи, стрімке вичерпання лімітів і бюджетів контексту, галюцинування контрактів API та вразливість до атак типу prompt injection.

З огляду на це актуальним науково-практичним завданням є проектування та дослідження архітектури агентних систем розробки програмного забезпечення, що функціонують у суворих інженерних межах («драбина довіри», TDD-контракти, прехоки безпеки, телеметрія токенів та витрат у реальному часі).

## Мета роботи
Розробка та дослідження автономної багатокрокової агентної системи генерації та супроводу веб-сервісів із замкненим контуром інструментальної валідації, багаторівневою безпекою доступу та наскрізним моніторингом операційних витрат.

## Завдання
1. Дослідити сучасні протоколи та форми комунікації LLM-агентів (Messages, Chat Completions, Responses, OpenTelemetry).
2. Реалізувати власний модульний агентний цикл із детермінованими умовами зупинки (ліміт кроків, бюджет токенів, Zod-схеми виходів).
3. Спроектувати механізми захисту середовища: заборона деструктивних операцій без підтвердження (`toolApproval`), конфігураційні прехоки захисту секретів та ізоляція файлової системи.
4. Порівняти ефективність, якість генерації та економічну вартість різних класів агентів (спеціалізовані CLI-агенти, хмарні моделі, відкриті локальні моделі з KV-кешуванням префіксів).
5. Інтегрувати систему розподіленого трасування та моніторингу вартості виконання завдань (OpenTelemetry + Langfuse).

## Об'єкт і предмет дослідження
- **Об'єкт дослідження:** Процес автоматизованої розробки, рефакторингу та тестування програмного забезпечення за допомогою штучного інтелекту.
- **Предмет дослідження:** Методи організації агентних циклів, протоколи інструментальної взаємодії (Tool Calling, MCP), механізми обмеження контексту та підтвердження дій для забезпечення надійності кодуючих агентів.

## Методи і технології
- **Мови та середовища:** TypeScript (Strict Mode), Node.js (>=22), Next.js (App Router).
- **Фреймворки та бібліотеки:** Vercel AI SDK 7, Zod, Vitest, Playwright E2E.
- **Моделі штучного інтелекту:** Google Gemini 2.5/3.8 Flash (хмарний рівень), Qwen 2.5 Coder 14B / Qwen 3 4B через локальний інференс Ollama з підтримкою KV-кешування префіксів.
- **Телеметрія та моніторинг:** OpenTelemetry NodeSDK, Langfuse Cloud SDK.
- **Методики вимірювання:** Порівняльний емпіричний аналіз кількості кроків, вхідних/вихідних токенів, похибки оцінки витрат, коефіцієнтів токенізації (ua/en) та часу відгуку.
